# データについて

- `fallback_menu.csv`：Web取得に失敗した場合だけ使う予備データです。2026年8月4日に学食サイトで確認できたおすすめ4品を保存しています。通常時は起動時にWebサイトから取得したデータを優先します。
- `dinner_menu.csv`：夕食提案機能を試すための例示データです。価格・栄養値はアプリ動作確認用の参考値であり、提出前に使用する料理や根拠資料に合わせて見直してください。

## standard_menu.csv

学食Webサイトの一覧に常時表示されない定番商品を補うデータです。
現在は大学生協の共通商品情報を基に、ライス4サイズと味噌汁を登録しています。
同名の商品がWebサイトから取得できた場合は、Webサイト側の値が優先されます。
